# Pulse Detect Pro (VitalFlow rPPG)

Современное веб-приложение для бесконтактного измерения пульса в реальном времени.

### Основные технологии:
- **MediaPipe FaceMesh**: ИИ для высокоточного трекинга 468 точек лица.
- **POS Algorithm (Plane-Orthogonal-to-Skin)**: Профессиональный алгоритм фильтрации сигнала пульса, устойчивый к изменениям освещения.
- **Signal Processing**: Оконное преобразование, детрендинг и частотный анализ для минимизации погрешности.
- **Glassmorphism UI**: Современный премиальный интерфейс с темной темой.

### Как запустить:
1. `npm install`
2. `npm start`
3. Откройте в браузере и разрешите доступ к камере.
